# Product Overview

LedgerMuse は、GCP 上で家計簿・レシートOCR・ナレッジ管理を一体化した学習兼将来商用化を見据えた Web アプリを目指す。

## Core Capabilities

- 支出の記録・分類とメモ／タグ／検索
- レシート画像アップロードと OCR 明細化（非同期処理）
- ナレッジ（メモ）蓄積・検索
- 安全な認証とユーザー単位のデータ分離
- 将来のダッシュボード／集計拡張を前提とした設計

## Target Use Cases

- 個人ユーザーが低コストで日常の支出管理とメモ整理を行う
- 学習目的で GCP の認証／ストレージ／DB／OCR／非同期処理を実践する

## Value Proposition

- GCP マネージドサービスを組み合わせた低運用コスト構成
- OCR から明細・ナレッジまでを一貫して扱えるワークフロー
- 学習フェーズから商用拡張への移行を考慮したアーキテクチャ
